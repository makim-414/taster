# Browser extension

Click the Taster button on any tab: it injects the detector (`detect.js`, a copy of `rules/detect.js`), the rule
names (`rules.js`) and `overlay.js`, which outlines every finding and lists the rules hit in a small panel. It asks
only for `activeTab` and `scripting`, so it can touch a tab only when you click the button there, and nothing leaves
the tab.

`detect.js` and `rules.js` are generated by `node scripts/build-docs.mjs`; `scripts/validate.mjs` fails when they
are stale. The web app serves the same three files at `/taster/*.js` for the bookmarklet on `/bookmarklet`.

Install before a store listing: open `chrome://extensions` (or `edge://extensions`), turn on developer mode, choose
Load unpacked and pick this folder.
